The project

Make the note useful at the moment a question arises.

The problem

An advisory note is valuable, but a reader may need an answer to one specific question. Finding the relevant passage and deciding whether it is conclusive takes time.

My role

I prepared the source note and set the requirements for an interface that keeps answers tied to it. The tool is built to make uncertainty visible rather than smooth it over.

How an answer is handled

  1. Find relevant passages.The service selects a bounded set of paragraphs from the private note.
  2. Answer from the source.The response cites passages and labels preliminary material.
  3. Show the boundary.It states what the note cannot establish and suggests further research questions.

The tool describes the note. It does not independently verify current market facts or provide legal advice.
